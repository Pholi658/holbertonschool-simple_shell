# Simple Shell

This is a simple UNIX command line interpreter written in C.  
It reads commands, executes them, and handles basic features like PATH, forking, and simple built-ins.

## How to compile
gcc -Wall -Werror -Wextra -pedantic *.c -o hsh

## How to run
./hsh

markdown
Copy code

## Features
- Displays a prompt
- Executes commands using PATH
- Handles `exit` and `env`
- Works in interactive and non-interactive mode
